# Геометрия (участник 2): калибровка камер

Зависимости модуля: `numpy`, `opencv-python`, `scipy`; для тестов — `pytest`. Shapely не нужен.

## Порядок работы

```bash
# 0. Разрешение и fps видео; медианный кадр без людей в ИСХОДНОМ разрешении
python -m mct.geometry.frames info   --video data/cam1.mp4
python -m mct.geometry.frames median --video data/cam1.mp4 --out data/frames/cam1_median.png

# 1. План: масштаб, пол, выходы, препятствия, опорные точки коридора -> calib/plan.json
python -m mct.geometry.tool plan --plan-image data/plan_clean.png --seg-m 1.2

# 2. Каждая камера: прямые, пары, видимый пол, столы, выходы -> calib/cam1.json
python -m mct.geometry.tool cam --camera cam1 --frame data/frames/cam1_median.png \
    --plan-image data/plan_clean.png
```

Запускать из корня репозитория с `PYTHONPATH=src` (или после `pip install -e .`).

## Как кликать, чтобы вышло точно

**Прямые (`l`)** — 8–12 линий по всему кадру, обязательно у краёв: швы плитки, низ стен,
дверные косяки. 8–15 точек на линию, зум колесом. Без прямых по краям кадра ошибка
на дальнем полу растёт в разы (проверено на синтетике).

**Пары (`p`)** — 10–14 точек на полу по всему кадру, включая дальний план: низ дверных
косяков, углы стен у пола, основания колонн. Мебель с плана не годится — она на плане
устарела (теннисного стола и футбола там нет). Сначала клик на кадре, потом та же точка на плане.

**`c`** — посчитать. В строке состояния и консоли:

| Что | Хорошо | Если плохо |
| --- | --- | --- |
| высота камеры `h` | 2,5–3,5 м | неверный масштаб плана или промах в паре |
| ошибка пар, среднее | ≤ 0,10 м | перекликнуть пары с большой ошибкой |
| LOO, среднее | ≤ 0,20 м | добавить пары там, где их нет |
| прямые | ≤ 2 px | убрать линию, которая на самом деле не прямая |

Жёлтая сетка 1×1 м должна лечь на швы плитки по всему полу; красный крестик —
куда модель кладёт точку плана, он должен совпасть с кликом.

**Пол (`f`)** — обвести видимый пол на кадре (без чёрной виньетки и стен); из него строится
зона обзора на плане. **Столы (`d`)** — всё, что закрывает ноги, включая теннисный стол.
**Выходы (`e`)** — двери и края кадра, через которые уходят люди (для запасного варианта без плана).

## Что внутри

| Файл | Что делает |
| --- | --- |
| `camera.py` | модель fisheye (своя, совпадает с `cv2.fisheye`, работает за 90°), проекция кадр↔план, проверка горизонта |
| `calibrate.py` | совместный подбор дисторсии и позы камеры по прямым и парам, мультистарт, отсев промахов, LOO |
| `distortion.py` | дисторсия по одним прямым (старт для совместного подбора) |
| `fit.py` | гомография по парам с RANSAC |
| `plan.py` | план в метрах, масштаб по отрезкам |
| `polygons.py` | полигоны на numpy |
| `tool.py` | окна для кликов; логика отделена от окон и покрыта тестами |
| `frames.py` | медианный кадр, кадр по времени |
| `viz.py` | сетка 1×1 м, полигоны |

Почему совместная калибровка, а не «дисторсия, потом H»: по одним прямым f и k
частично взаимозаменяемы, и на краях кадра без линий ошибка доходит до 0,5 м.
Метрические пары снимают неоднозначность. Физическая модель камеры даёт её высоту
(проверка здравого смысла), а позже — восстановление ног за столом прямо из геометрии.
